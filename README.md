# Seemi Patel Portfolio

A clean, editorial-style UX/Product portfolio inspired by the structure and feel of the reference portfolio.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` with your email.
2. Replace the LinkedIn URL with your actual LinkedIn profile.
3. Replace each `#` case-study link with your project URL.
4. Add your resume PDF if desired.
5. Deploy the folder to Vercel, Netlify, or GitHub Pages.

The design is responsive and works on desktop and mobile.
